# C++ Pointers and Memory Management
## Overview

This project demonstrates the fundamentals of C++ pointers, which includes : 
- Memory addresses
- Poinetrs declaration and dereferencing
- Poineter arithmetic
- Array traversal using pointers 
- Functions, call by poinetrs

## Compilation
### pointer_basics.cpp

```bash 
# Compile
g++ src/pointer_basics.cpp -o pointer_basics
# Execute
./pointer_basics
```
```bash 
# Compile
g++ src/array_pointers.cpp -o array_pointer
```
