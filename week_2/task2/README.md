Array and String Operations in C++
---
A C++ assignment demonstrating various array and string operations using user-defined functions, header files, and modular programming.

Features
---
Array Operations

- Input Array
- Print Array
- Sum of Array Elements
- Find Largest Element
- Find Smallest Element
- Search an Element
- Reverse an Array
- Count Even Numbers
- Count Odd Numbers

String Operations

- Find String Length
- Count Vowels
- Count Alphabets
- Count Consonants
- Reverse a String
- Compare Two Strings

Concepts Used
---
- Functions
- Header Files
- Arrays
- Strings
- References
- Loops
- Conditional Statements
- Modular Programming
