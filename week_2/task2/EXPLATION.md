 Array and String Operations using Functions in C++

Objective

The objective of this assignment is to implement various array and string operations using user-defined functions in C++. The program demonstrates the use of arrays, strings, loops, conditional statements, references, header files, and function definitions.

---

Array Operations

The following functions were implemented for one-dimensional arrays:

1. Input Array

Reads elements from the user and stores them in an array.

2. Print Array

Displays all elements of the array.

3. Sum of Array Elements

Calculates and returns the sum of all elements present in the array.

4. Find Largest Element

Traverses the array and returns the largest value.

5. Find Smallest Element

Traverses the array and returns the smallest value.

6. Search Element

Searches for a specific element in the array and returns its index if found. Returns -1 otherwise.

7. Reverse Array

Reverses the order of elements in the array using a custom swap function.

8. Count Even Numbers

Counts the total number of even elements in the array.

9. Count Odd Numbers

Counts the total number of odd elements in the array.

---

String Operations

The following functions were implemented for strings:

1. String Length

Calculates the length of a string without using built-in string length functions.

2. Count Vowels

Counts the number of vowels present in a string.

3. Count Alphabets

Counts the number of alphabetic characters present in a string.

4. Count Consonants

Calculates consonants by subtracting vowels from the total alphabet count.

5. Reverse String

Reverses the string using a custom swap function.

6. Compare Strings

Compares two strings character by character and returns whether they are equal.

7. Helper Functions

Additional helper functions were implemented:

- isVowel() – Checks whether a character is a vowel.
- isAlphabet() – Checks whether a character is an alphabet.
- swap() – Swaps two characters using references.
